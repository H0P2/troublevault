# TroubleVault

문제 해결 과정을 **문제 → 원인 → 해결 방법 → 결과** 구조로 기록하고, 이후 검색·필터·즐겨찾기를 통해 다시 찾아볼 수 있도록 만든 브라우저 기반 개인 트러블슈팅 아카이브입니다.

## 프로젝트 개요

TroubleVault는 개발, 네트워크, Linux, 서버 실습 중 발생한 문제를 단순 메모가 아니라 재사용 가능한 형태로 정리하기 위해 제작했습니다.

각 기록은 다음 항목으로 구성됩니다.

- 제목
- 카테고리
- 태그
- 문제
- 원인
- 해결 방법
- 결과
- 생성/수정 시각
- 즐겨찾기 상태

## 주요 기능

- 새 문제 해결 기록 생성
- 저장된 기록 조회
- 기존 기록 수정
- 기록 삭제
- 즐겨찾기 등록 / 해제
- 즐겨찾기 우선 정렬
- 제목·내용·태그 통합 검색
- 카테고리 필터
- 검색 + 카테고리 필터 조합
- LocalStorage 기반 영구 저장
- 새로고침 후 기록 자동 복원
- Matrix Rain 배경 On / Off
- 반응형 3D 스타일 UI
- 키보드 조작 지원
- `prefers-reduced-motion` 대응

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Canvas API
- `requestAnimationFrame`
- DOM API

별도의 서버, 데이터베이스, 프레임워크 또는 외부 API를 사용하지 않습니다.

## 데이터 저장 방식

사용자가 작성한 기록은 브라우저의 `LocalStorage`에 저장됩니다.

따라서:

- 서버로 기록을 전송하지 않습니다.
- 같은 브라우저에서는 새로고침 후에도 기록이 유지됩니다.
- 브라우저의 사이트 데이터 또는 LocalStorage를 삭제하면 기록도 삭제됩니다.
- API Key, 비밀번호, 토큰 등의 비밀값을 사용하지 않습니다.

## 사용 방법

1. 왼쪽의 `New Trouble Record` 폼에 기록을 입력합니다.
2. `기록 저장` 버튼을 누릅니다.
3. 오른쪽 `Vault Records` 영역에서 저장된 기록을 확인합니다.
4. 필요하면 `수정`, `삭제`, `즐겨찾기` 기능을 사용합니다.
5. 검색창과 카테고리 필터를 이용해 원하는 기록을 다시 찾습니다.
6. 상단 `Matrix On / Off` 버튼으로 배경 애니메이션을 켜거나 끌 수 있습니다.

## CRUD 구조

| 기능 | 동작 |
|---|---|
| Create | 새 기록 저장 |
| Read | 저장된 기록 목록 조회 |
| Update | 기존 기록 수정 |
| Delete | 기록 삭제 |

추가로 즐겨찾기 기능을 제공하며, 즐겨찾기된 기록은 목록 상단에 우선 표시됩니다.

## 접근성

- 주요 상호작용에 실제 `button` 요소 사용
- `Tab` 키로 주요 기능 이동 가능
- `Enter` / `Space` 키로 버튼 실행 가능
- `:focus-visible`을 통한 초점 표시
- Matrix 애니메이션을 사용자가 직접 끌 수 있음
- `prefers-reduced-motion` 환경에서는 애니메이션을 줄이도록 처리
- 텍스트 출력에 `textContent`를 사용해 입력 HTML이 실행되지 않도록 처리

## 개발 중 발견하고 수정한 문제

### 1. Matrix 초기화 순서 오류

**수정 전**

Matrix Rain 초기화 과정에서 `fontSize`가 선언되기 전에 참조되어 `ReferenceError`가 발생했습니다. JavaScript 실행이 해당 지점에서 중단되면서 Matrix 버튼뿐 아니라 페이지의 다른 클릭 기능도 함께 작동하지 않았습니다.

**수정 후**

Matrix 관련 상수와 상태를 먼저 초기화한 뒤 애니메이션을 시작하도록 실행 순서를 변경했습니다. 또한 `startMatrixRain()`과 `stopMatrixRain()`으로 기능을 분리해 On / Off를 반복해도 애니메이션 루프가 중복 생성되지 않도록 수정했습니다.

### 2. 샘플 카드와 실제 저장 데이터 중복 표시

**수정 전**

초기 UI 확인을 위해 `index.html`에 직접 작성했던 Postfix와 OSPF 예시 카드가 LocalStorage에서 불러온 실제 기록과 함께 표시되었습니다.

**수정 후**

HTML에 고정된 예시 카드를 제거하고 `recordList`의 모든 카드를 JavaScript가 LocalStorage의 실제 기록을 바탕으로 생성하도록 통일했습니다.

### 3. 수정·삭제 후 데이터 지속성 확인

**검사 내용**

기록을 수정하거나 삭제한 뒤 새로고침했을 때 이전 상태가 다시 나타나는 문제가 없는지 확인했습니다.

**최종 상태**

수정 사항과 삭제 상태가 LocalStorage에 즉시 반영되며, 새로고침 후에도 최종 상태가 유지됩니다.

## 테스트한 주요 동작

- 기록 추가 후 새로고침 → 기록 유지
- 기록 수정 후 새로고침 → 수정된 내용 유지
- 기록 삭제 후 새로고침 → 삭제된 기록 복원되지 않음
- 즐겨찾기 후 새로고침 → 즐겨찾기 상태 유지
- 검색 및 카테고리 필터 동시 적용
- Matrix On → Off → On 반복 동작
- LocalStorage 테스트 성공
- 브라우저 Console 빨간 오류 0건

## 프로젝트 목적

실습 중 해결한 문제를 다시 같은 방식으로 검색하지 않도록, 문제 해결 과정을 구조화해 축적하고 재사용할 수 있는 개인 기술 지식 저장소를 구현하는 것이 목적입니다.

이 프로젝트를 통해 다음 내용을 직접 구현했습니다.

- 브라우저 데이터 저장
- CRUD 처리
- 동적 DOM 생성
- 검색 및 필터링
- 상태 관리
- Canvas 애니메이션
- 반응형 UI
- 키보드 접근성
